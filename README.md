# Эмулятор оболочки ОС — вариант №9, этап 1

Учебный проект по дисциплине **«Конфигурационное управление»**.

В проекте реализован первый этап практической работы для варианта №9:
минимальный графический эмулятор командной оболочки с поддержкой REPL.

REPL расшифровывается как **Read–Eval–Print Loop** — цикл чтения команды,
её обработки и вывода результата.

## Требования к системе

Для запуска на Windows необходимы:

- Windows 10 или Windows 11;
- Python версии 3.9 или новее;
- Python Launcher `py` или команда `python` в системной переменной `PATH`;
- библиотека `tkinter`;
- графическая среда Windows.

`tkinter` обычно устанавливается вместе с официальным Python для Windows.
При установке Python с сайта <https://www.python.org/downloads/windows/>
необходимо оставить включённым стандартный компонент **Tcl/Tk and IDLE**.

Внешние Python-зависимости проекту не требуются.

## Запуск в Windows через `run.bat`

1. Распакуйте архив проекта.
2. Откройте папку `shell-emulator-stage1`.
3. Дважды нажмите на файл `run.bat`.

Также можно открыть CMD в папке проекта и выполнить:

```bat
run.bat
```

Скрипт автоматически:

1. переходит в папку проекта;
2. устанавливает `PYTHONPATH` на папку `src`;
3. проверяет наличие команды `py`;
4. запускает `py -3 -m shell_emulator`;
5. если `py` недоступен, запускает `python -m shell_emulator`.

## Работа с графическим интерфейсом

После запуска откроется окно эмулятора.

В нижнее поле вводится команда. Для выполнения команды нажмите `Enter`.

## Поддерживаемые команды

### `ls`

Команда-заглушка. Она не просматривает содержимое файловой системы, а только
выводит собственное имя и переданный аргумент.

Допускается не более одного аргумента:

```text
> ls documents
Команда: ls
Аргументы: documents
```

При передаче двух аргументов появляется ошибка:

```text
> ls one two
Ошибка: Неверное число аргументов для ls: ожидался максимум 1
```

### `cd`

Команда-заглушка. На первом этапе она не изменяет текущую директорию.

```text
> cd "folder with spaces"
Команда: cd
Аргументы: folder with spaces
```

### `exit`

Завершает работу приложения:

```text
> exit
Завершение работы.
```

Команда `exit` не принимает аргументы:

```text
> exit now
Ошибка: Неверные аргументы: exit не принимает аргументы
```

## Запуск тестов в Windows

### CMD

```bat
set PYTHONPATH=src
py -3 -m unittest discover -s tests -v
```

Если команда `py` отсутствует:

```bat
set PYTHONPATH=src
python -m unittest discover -s tests -v
```

### PowerShell

```powershell
$env:PYTHONPATH = "src"
py -3 -m unittest discover -s tests -v
```

Ожидаемый результат — семь успешно пройденных тестов:

```text
Ran 7 tests
OK
```

Тесты проверяют:

- выполнение команды `ls`;
- обработку аргументов в кавычках;
- выполнение команды `cd`;
- неизвестные команды;
- слишком большое количество аргументов;
- команду `exit`;
- ошибку при передаче аргументов в `exit`;
- пустую строку.

## Запуск тестов в Linux/macOS

```bash
PYTHONPATH=src python3 -m unittest discover -s tests -v
```
